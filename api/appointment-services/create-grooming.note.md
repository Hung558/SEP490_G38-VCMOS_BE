# API Documentation: Create Grooming Note

A Groomer creates the grooming note (before/after notes, before/after photos, recommendations) for a service that is assigned to them. Photos are uploaded to Cloudinary and the returned HTTPS URLs are stored in the note.

## Endpoint

| | |
|---|---|
| **Method** | `POST` |
| **URL** | http://localhost:9999/api/appointment-services/:id/grooming-note |
| **Auth** | Required: `Authorization: Bearer <token>`, role `Groomer` |
| **Content-Type** | `multipart/form-data` (when uploading photos) or `application/json` (text only) |

## Path parameters

| Parameter | Type | Description |
|---|---|---|
| `id` | string (ObjectId) | ID of the appointment service (`AppointmentService`) the note belongs to. |

## Request body

At least one text field **or** one photo is required. Any other field (including `beforePhotoUrl`, `afterPhotoUrl`, `createdAt`) is rejected: photo URLs are generated by the server from the uploaded files.

| Field | Type | Required | Description |
|---|---|---|---|
| `beforeNote` | string | No | Note taken before grooming. Trimmed, max 1000 characters. Empty values are ignored. |
| `afterNote` | string | No | Note taken after grooming. Trimmed, max 1000 characters. Empty values are ignored. |
| `recommendations` | string | No | Recommendations for the pet owner. Trimmed, max 1000 characters. Empty values are ignored. |
| `beforePhoto` | file | No | Photo taken before grooming. JPEG, PNG or WebP, max 5MB. Stored as `groomingNote.beforePhotoUrl`. |
| `afterPhoto` | file | No | Photo taken after grooming. JPEG, PNG or WebP, max 5MB. Stored as `groomingNote.afterPhotoUrl`. |

**Business rules**

- The service must be assigned to the logged-in Groomer (`assignedStaffId`).
- The service status must be `InProgress` or `Done`.
- A service can have only one grooming note.

**Example (cURL, multipart)**

```bash
curl -X POST http://localhost:9999/api/appointment-services/6ad96d4a9664da6b2c0d8d70/grooming-note \
  -H "Authorization: Bearer <token>" \
  -F "beforeNote=Lông rối nhiều, da khô" \
  -F "afterNote=Đã tắm và cắt tỉa gọn gàng" \
  -F "recommendations=Chải lông mỗi ngày" \
  -F "beforePhoto=@before.jpg;type=image/jpeg" \
  -F "afterPhoto=@after.jpg;type=image/jpeg"
```

**Example (JSON, text only)**

```json
{
  "afterNote": "Đã tắm và cắt tỉa gọn gàng",
  "recommendations": "Chải lông mỗi ngày"
}
```

### 400 Bad Request: validation failed

Errors return a single `message` (no `errors` object). Possible messages:

| Message | Cause |
|---|---|
| `ID dịch vụ lịch hẹn không hợp lệ` | `:id` is not a valid ObjectId. |
| `Không được truyền các trường: <fields>` | Body contains fields other than `beforeNote`, `afterNote`, `recommendations`. |
| `<field> phải là chuỗi` | A text field is not a string. |
| `<field> tối đa 1000 ký tự` | A text field is longer than 1000 characters. |
| `Vui lòng nhập ít nhất một ghi chú hoặc tải lên ít nhất một ảnh` | No text and no photo provided. |
| `Ảnh phải có định dạng JPEG, PNG hoặc WebP` | Uploaded file has an unsupported type. |
| `Mỗi ảnh tối đa 5MB` | An uploaded photo is larger than 5MB. |
| `Chỉ nhận ảnh qua các trường beforePhoto và afterPhoto (mỗi trường 1 ảnh)` | A file was sent in a different field, or more than one file in a field. |
| `Chỉ được tải lên tối đa 2 ảnh` | More than 2 files were sent. |

```json
{ "message": "Vui lòng nhập ít nhất một ghi chú hoặc tải lên ít nhất một ảnh" }
```

### 401 Unauthorized: not logged in

```json
{ "message": "Chưa đăng nhập" }
```
Or when the token is invalid or expired:
```json
{ "message": "Token không hợp lệ hoặc đã hết hạn" }
```

### 403 Forbidden

Role is not `Groomer`:
```json
{ "message": "Bạn không có quyền thực hiện chức năng này" }
```
The service is not assigned to the logged-in Groomer:
```json
{ "message": "Bạn chỉ có thể thao tác trên dịch vụ được phân công cho mình" }
```
Or the account is locked / inactive:
```json
{ "message": "Tài khoản đã bị khoá, vui lòng liên hệ quản trị viên" }
```

### 404 Not Found: service does not exist

```json
{ "message": "Không tìm thấy dịch vụ trong lịch hẹn" }
```

### 409 Conflict

Service status is not `InProgress` or `Done`:
```json
{ "message": "Chỉ có thể tạo ghi chú cho dịch vụ đang thực hiện hoặc đã hoàn thành (hiện tại: \"Booked\")" }
```
The service already has a grooming note:
```json
{ "message": "Dịch vụ này đã có ghi chú chăm sóc" }
```
Two requests raced, or the service was reassigned while the request was running:
```json
{ "message": "Dịch vụ này đã có ghi chú chăm sóc hoặc không còn được phân công cho bạn" }
```

### 502 Bad Gateway: photo upload failed

No note is saved and any photo already uploaded in this request is removed from Cloudinary.
```json
{ "message": "Không thể tải ảnh lên, vui lòng thử lại sau" }
```

### 500 Internal Server Error
```json
{ "message": "Lỗi máy chủ, vui lòng thử lại sau" }
```
